# ⚔️ LeetCode Leveler v1.0 ⚔️

## 1. About Me
I switched from an electrical engineering major to software because it has always been something I was interested in learning. Since I joined the curriculum late, I struggled to understand the basic syntax building blocks while watching classmates create advanced pages and scripts. This comparison gap caused deep imposter syndrome, making me feel far behind my peers.

## 2. Problem Statement
**When** I was in my room after finishing homework, I tried to work through a difficult LeetCode problem,
**I struggle to** maintain my focus and determination, easily getting intimidated by the challenge and letting my brain trick me into seeking an escape,
**which costs me** up to 3 hours of prime study time wasted on entertainment tabs like YouTube, leaving me too exhausted to watch solution walkthroughs or try again before bed.
**This happens because** my computer environment makes distraction too effortless. When LeetCode gets frustrating, having instant access to YouTube and Netflix tabs provides an immediate path of least resistance to avoid the discomfort of feeling stuck.
**Right now I** am trying to build discipline by putting my phone completely out of view, **but** my computer desktop is still cluttered with open entertainment tabs, meaning I use "eating a snack" as an excuse to watch a video, which inevitably snowballs into hours of doom-watching long after I'm done eating.

**I'll know this is solved when** my logged study hours consistently exceed my entertainment hours, and I treat entertainment strictly as a hard-earned reward right before going to bed.

## 3. Existing Solutions
*   **Placing the phone out of view:** Fell short because my open computer web tabs (YouTube/Netflix) remained an instant escape path during frustrating coding sessions.
*   **Setting countdown timers:** Fell short because I would get too tired after finishing just one challenge, letting exhaustion take over instead of pushing through the friction.

**The gap:** What is still missing for me is an active, centralized system that bridges my daily study records with strict task sorting so I can visually see my progress instead of wandering off to entertainment tabs when I feel stuck.

## 4. Features & Benefits
*   **Linear Search Log Filter (MVP):** Lets me instantly isolate unsolved problem strings or filter study notes by calendar slices.
*   **Terminal UI (MVP):** Keeps me fully focused in a command-line window, completely removing browser workspaces where distracting entertainment tabs hide.
*   **Interactive Quest Submission (MVP):** Converts boring problem tracking into a retro text-adventure sequence, requiring me to declare my coding language and explain my logic in detail before receiving my milestone EXP bounty.
*   **Adventure Day Checkpoint (MVP):** Explicitly pauses the game loop after a quest to ask if I wish to save progress and log off, breaking late-night study exhaustion.
*   **Persistent JSON Save File (MVP):** Acts like a gaming memory card to securely write my variables to the disk.
*   **EXP Level-Up System (Later):** Adds a mathematical scaling experience tracker.

## 5. Tech Stack
*   **Front end:** CLI (Command Line Interface) written in Python using native layout printing. It provides a retro text-adventure aesthetic that keeps me away from browser tabs.
*   **Back end:** Local Python Scripts using standard loop architectures. Keeps the project light, fast, and entirely offline.
*   **Data Storage:** Local JSON text configuration file. Acts as a persistent save file to keep track of my project states when the terminal closes.
*   **Hosting:** GitHub repository for code backups, change tracking, and version management.
